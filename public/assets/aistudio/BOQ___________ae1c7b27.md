# Construction 模块 1：BOQ 分包评标拉平矩阵（Bid Leveling）Excel 实施方案

## 第一部分：模块层级拆解与整体架构方案（Step 1）

### 1.1 面向业务问题的模块拆解

针对工程建设（Construction）招采评标场景中，商务经理与造价工程师面临的核心痛点——**收到 3 至 4 家分包商格式混乱的报价单，表面最低价分包商故意漏报防水、临设等子项制造“假最低价”，同时在后期易发生工程变更的子项上恶意报高单价（Unbalanced Bidding / 不平衡报价）**，本实施方案将 Excel 模板按“参数控制 $\rightarrow$ 数据采集 $\rightarrow$ 计算拉平 $\rightarrow$ 决策呈现”的自上而下分析路径，拆解为 **4 大业务模块（共 4 个 Sheet）**：

| 模块层级 | 模块名称 | 包含 Sheet 数量 | Sheet 命名 | 核心业务用途与解决的分析问题 | 
| ----- | ----- | ----- | ----- | ----- | 
| **模块 0（全局控制层）** | 全局参数与评标规则配置模块 | 1 个 | `00_全局参数配置` | 集中存放本位币符号、漏项补齐规则（Plug Rate 模式）、漏项惩罚上浮率、不平衡报价偏离预警阈值（如 $25\%$）、内控预算容忍度及分包商名称映射。实现“单点修改参数，全局自动重算”。 | 
| **模块 1（数据输入层）** | 基准工程量清单与原始报价采集模块 | 1 个 | `01_BOQ与原始报价录入` | 作为全表唯一的**手工录入/粘贴区**。用于导入招标方基准工程量清单（BOQ 编码、项目名称、计量单位、工程量、内控基准单价）及粘贴 3 家分包商的原始报价单价（漏报项直接留空）。 | 
| **模块 2（分析计算层）** | 漏项自动补齐与单价偏离度计算引擎 | 1 个 | `02_评标拉平与偏离计算` | 全表核心算法引擎（纯公式溢出区，无需人工干预）。利用动态数组自动识别空白漏报项并按参数表设定的“内控基准价或其余分包均价”自动补齐单价（Plug Rate）；同步计算拉平后合价、漏项补齐金额、各子项单价与内控基准价的偏离度及红旗预警状态。 | 
| **模块 3（决策呈现层）** | 评标拉平看板与询标澄清清单模块 | 1 个 | `03_评标看板与澄清清单` | 面向招采委员会的最终行动看板。一屏输出三大核心成果：① **同口径真实总价排名**（对比表面排名与拉平排名，直接揭穿“假最低价”）；② **漏项金额汇总表**；③ **不平衡报价红旗预警与询标澄清清单**（自动筛选并标红单价偏离基准大于 $25\%$ 的恶意高报子项，生成可直接发出的询标质询表）。 | 

### 1.2 “数据 $\rightarrow$ 分析 $\rightarrow$ 呈现”跨表逻辑流向图

```
[00_全局参数配置] (参数源：本位币符号 / Plug Rate模式 / 25%高报阈值 / 预算上限 / 分包商名称)
       │
       ▼ (绝对引用 $B$5:$B$12 注入计算与看板规则)
[01_BOQ与原始报价录入] ──(FILTER / XLOOKUP 动态数组溢出抓取)──► [02_评标拉平与偏离计算]
  • 基准BOQ清单录入                                              • 空白漏报自动识别与Plug Rate补齐
  • 3家分包商原始单价粘贴(漏报留空)                                • 同口径拉平合价 & 漏项金额计算
                                                                 • 单价偏离度计算 & 红旗预警标记
                                                                        │
                                             ┌──────────────────────────┴──────────────────────────┐
                                             ▼ (VSTACK / SUM 聚合溢出)                             ▼ (FILTER 动态筛选溢出)
                                [03_评标看板与澄清清单 - 上区]                        [03_评标看板与澄清清单 - 下区]
                                  • 输出1：同口径真实总价排名（揭穿假最低价）             • 输出3：不平衡报价红旗预警（>25%）
                                  • 输出2：各分包商漏项金额汇总表                         与自动生成的询标澄清清单

```

* **防碰撞架构设计**：在 `03_评标看板与澄清清单` 中，输出 1（同口径真实总价排名）与输出 2（漏项金额汇总表）均以 3 家参评分包商为固定维度，合并部署在看板上部固定行区（第 5 至 7 行）；输出 3（不平衡报价红旗预警与询标澄清清单）部署在第 12 行起始的下部开放区，向下无限动态溢出，从物理结构上彻底杜绝多个动态数组上下堆叠引发的 `#SPILL!` 溢出冲突。
